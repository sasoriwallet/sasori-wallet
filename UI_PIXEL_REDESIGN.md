# Sasori Wallet 0.0.1v — UI notes

- WAM logo is shown beside the main balance.
- Sasori branding uses the Sasori logo.
- Send and Receive are prominent Home actions.
- Sidebar is Home / Settings / Donate.
- Transactions are accessed from Home → View all instead of sidebar navigation.
- Address Book is removed from the UI and renderer IPC bridge.
- Transaction rows open a detail modal.
- Pending balance is shown below the primary available balance.
- Home balance refreshes every 3 seconds.
- The stable primary receiving address is reused instead of changing every refresh.
- First-run and startup screens use the pixel-art styling and show node synchronization state.
